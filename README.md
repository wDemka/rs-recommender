# Рекомендательная система фильмов

Задание 4.1 (API) и 4.2 (приложение). Данные — MovieLens ml-latest-small
(610 пользователей, около 100 000 оценок), хранятся в SQLite.

## Файлы

- database.py — база SQLite (movies, ratings), загрузка датасета из CSV
- engine.py — алгоритмы рекомендаций (коллаборативная и контентная фильтрация)
- main.py — REST API на FastAPI, порт 8000
- streamlit_app.py — приложение на Streamlit, работает через API
- recommender_system.ipynb — ноутбук: анализ данных, графики, оценка качества
- reports/ — графики и таблицы, которые сохраняет ноутбук

## Как запускать

1. run_api.bat — поднимет сервер API (http://127.0.0.1:8000, документация /docs)
2. run_app.bat — откроет приложение (http://localhost:8501)
3. recommender_system.ipynb — открыть в Jupyter или VS Code, выбрать интерпретатор из .venv

## Команды API

- GET /api/top10 — топ популярных фильмов
- GET /api/recommend/user_based/{user_id} — рекомендации по похожим пользователям
- GET /api/recommend/item_based/{user_id} — рекомендации по похожим фильмам
- GET /api/recommend/content/{movie_id} — похожие фильмы по жанрам
- GET /api/personal/{user_id} — персональные рекомендации
- GET /api/users, /api/users/{user_id}/ratings — пользователи и их оценки
- GET /api/movies?search=... — поиск фильмов
- POST /api/rate — сохранить оценку (user_id, movie_id, rating от 0.5 до 5)
- GET /api/help — справка по командам и параметрам

## Как считают рекомендации

Оценки центрируют (вычитают средний балл пользователя), похожесть — косинусное
расстояние. По пользователям: 30 ближайших соседей, их оценки суммируются с весом
похожести. По фильмам: для каждого фильма держим 40 самых похожих фильмов.
Контентные: векторы жанров TF-IDF. Персональные: два CF-списка объединяем по
рангам (RRF). Новые оценки из приложения сразу учитываются в рекомендациях.
